Added :class:`~aiohttp_client_middlewares.SSRFMiddleware` and
:class:`~aiohttp_client_middlewares.SSRFConnector`, a two-layer defense against
server-side request forgery -- the connector validates every resolved address
(IP-literals, DNS answers, and each redirect hop) for direct connections, while
the middleware enforces URL-scheme and hostname rules, which is the only
constraint available when a forward proxy resolves the target
-- by :user:`rodrigobnogueira`.
